# First steps after installation

[Documentation](../README.md) / Getting started / First steps

## Find Moggcord settings

Open Discord's user settings and find **Moggcord Settings**. The section includes **Moggcord**, **Plugins**, **Themes**, **Updater** and **Backup & Restore**. If the section is absent, confirm that you opened the channel you selected in the installer.

## Choose your plugins

Open **Plugins**. Both bundled collections are included. Use search and collection filters to find an available plugin; **Show All** displays both collections.

Fresh installations enable four plugins by default: FakeDeafen, ExportDM, CustomProfile and TokenImporter. Other available plugins can be enabled individually. Existing settings can produce a different enabled count. Internal dependencies are not ordinary selectable plugins.

Enable a few plugins at a time and follow any restart prompt. See [Plugins and defaults](../guides/plugins.md) for how availability differs from activation.

## Add your styling

Use **Themes** for local stylesheets and online theme links. **Open Themes Folder** opens the directory for local theme files. **Edit QuickCSS** is available from Moggcord's quick actions for small personal CSS changes.

Start with one theme so that conflicting styles are easier to diagnose. See [Themes and QuickCSS](../guides/themes.md).

## Check the version

Open **Updater**, choose **Check for Updates**, and follow the result. An update can require a complete Discord restart, including its tray process; reloading the window does not replace the main process.

## Make a backup

In **Backup & Restore**, choose **Export All Settings** and keep the JSON file somewhere private. A settings export does not contain community plugin source files or downloaded theme files. The [backup guide](../guides/backup-and-restore.md) explains what to copy when moving computers.

## Connect the community website only if needed

The normal installer does not register automatic website installation by itself. Follow [Connector setup](../community/setup.md) if you want a community Download button to compile an upload, install it locally and restart your selected channel.
