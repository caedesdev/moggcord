# Moggcord 1.18.57

[Documentation](../README.md) / [Release notes](README.md) / 1.18.57

- Use the blue and black MC artwork for the installer logo and application icon.
- Render the installer header directly from the transparent 1024 px PNG instead of enlarging a 32 px Windows icon.
- Load the large embedded Windows icon for clearer taskbar rendering on scaled displays.

## Downloads

Choose the installer for Windows, macOS or Linux from this release. The Windows installer includes the .NET runtime. macOS and Linux packages remain previews; they are built and verified on their native runners, but compatibility with every Discord setup is not guaranteed.

Technical update files and checksums are published separately under [updates-v1.18.57](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.57).
