# Moggcord 1.18.44

[Documentation](../README.md) / [Release notes](README.md) / 1.18.44

## Choose your installer

| System | Download |
| --- | --- |
| Windows x64 | `Moggcord-Installer.exe` |
| macOS Intel and Apple Silicon | `Moggcord-Installer-macOS.dmg` |
| Linux x64 | `Moggcord-Installer-Linux.AppImage` or `Moggcord-Installer-Linux.deb` |

The main release now contains only these four installer packages. Update bundles, metadata, checksums and verification reports are in a [separate technical release](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.44).

## One-time updater migration

Users on 1.18.43 or older should download the current installer and choose **Repair Moggcord** once. Older clients only look for update ZIPs in the main release. Version 1.18.44 also reads the version-matched technical release, so future automatic updates can use the smaller desktop-only archive without cluttering the installer list.

macOS and Linux remain preview platforms. The macOS app is ad hoc signed and not Apple notarized. Linux x64 supports the official Discord DEB/TAR installations; Flatpak and Snap remain unsupported by this installer.
