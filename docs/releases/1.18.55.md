# Moggcord 1.18.55

[Documentation](../README.md) / [Release notes](README.md) / 1.18.55

- Add server icons and search by name or ID to both Server Cloner selectors. The target list includes only other servers where you have Administrator permission.
- Choose whether to keep existing content, delete channels, delete roles or delete both before cloning. Use Clean up only to prepare the target without copying anything.
- Show the number of channels and roles to delete and require the target server name before deletion. Keep protected roles and stop cloning if cleanup fails or is cancelled.
- Keep existing content by default and retain the existing cloning transport and copy options.
- Add regression tests for target isolation, role hierarchy, permission checks, confirmation, cancellation and cleanup without cloning.
