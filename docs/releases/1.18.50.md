# Moggcord 1.18.50

[Documentation](../README.md) / [Release notes](README.md) / 1.18.50

- The Windows installer includes its own .NET runtime in the single executable. Users do not need to install the .NET Desktop Runtime separately.
- Automatic installer updates and the compact welcome screen are included. The download is larger because it also contains the runtime.

Use this installer file to get the bundled runtime. Previously downloaded framework-dependent installers still require their original runtime.
