# Moggcord 1.18.46

[Documentation](../README.md) / [Release notes](README.md) / 1.18.46

## Automatic community installation

- Moggcord starts its local community service when the desktop client opens. Existing installations receive the service through the normal Moggcord updater.
- Clicking Download on moggcord.cc uses the browser's local-app permission and installs into the detected Moggcord channel: Discord Stable, Canary, PTB or Development.
- Detection checks the current Discord host and excludes unmodified Discord and other loaders. It does not fall back to an older patched app after a Discord update. Multiple matching installations require a deliberate channel choice.
- The independent local service stays available while Discord restarts and reports completed installation or a concrete error to the existing download notification.
- The compiler is prepared only when a new code plugin needs building. Its package must match the running Moggcord version and the published checksum. Existing community plugin source is preserved.
- The service is included in the verified desktop files and small update archive. Missing or damaged service files prevent a successful update report.

Fully restart Discord after updating. On the website, allow local-app access when the browser asks. The plugin download page keeps its existing Download workflow.
