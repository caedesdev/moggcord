# Moggcord 1.18.59

[Documentation](../README.md) / [Release notes](README.md) / 1.18.59

## Voice message preview

- Play, pause and seek through a recording or a selected audio file before sending it.
- Show a playback error when the selected audio cannot be played. The preview stays available if duration or waveform extraction fails.
- Handle changes in Discord's notification API so a missing notification handler does not interrupt the voice message dialog.

## Downloads

Update from the Moggcord settings in Discord or use the installer for your operating system. The macOS and Linux installers are preview builds. Technical assets and checksums are available under [updates-v1.18.59](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.59).
