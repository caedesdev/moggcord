# Moggcord 1.18.45

[Documentation](../README.md) / [Release notes](README.md) / 1.18.45

## Animated settings branding

- The Moggcord Settings sidebar heading uses a blue/violet gradient with a subtle glow. It scrolls continuously from left to right at a steady speed, completing a seamless cycle every two seconds.
- Branding is part of the core Settings integration, so no optional plugin needs to be enabled.
- Reduced-motion preferences keep the gradient static. Forced-color mode uses readable system text.
- The legacy SettingsGlint entry is retained for settings compatibility, hidden from the optional plugin list, and no longer scans the document or runs a polling timer.
- Sidebar navigation, searchable panel titles, stealth behavior and the four default-enabled plugins are preserved.

Fully restart Discord after updating to load the new renderer code. Clients older than 1.18.44 need the latest installer's Repair action once for the separated update-file layout.

## Downloads

The main release contains only the Windows EXE, universal macOS DMG and Linux x64 AppImage/DEB installers. [Technical update files and checksums](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.45) are stored separately. macOS/Linux remain preview platforms; the macOS app is not Apple notarized.
