# Moggcord 1.18.58

[Documentation](../README.md) / [Release notes](README.md) / 1.18.58

## Choose your Discord installation

Downloading a community plugin or theme from [moggcord.cc](https://moggcord.cc) now lets you choose between detected Moggcord installations in Discord, Canary, PTB and Development. The connector installs into that target and restarts only that client. Installed and disabled states follow the selected client.

The local service exposes channel selection without changing manually pinned configurations. An ambiguous shared install link stops before downloading or modifying files, allowing the website to request a choice. Repeated jobs are matched by both package and channel.

If automatic installation fails, the website downloads a ZIP containing the complete plugin folder structure. Single-file plugins and themes are also packaged correctly. Closing the selection dialog cancels without installing or downloading anything.

Existing users need this client update for the channel chooser. Older connectors can use the website's ZIP fallback. See [Community downloads](../community/installing-and-sharing.md).

## Downloads

Choose the installer for your operating system. Existing installations can use the Moggcord updater or **Repair** in the current installer. Technical update files and checksums remain separate under [updates-v1.18.58](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.58).

Validation: standalone desktop build, 101 community/connector/release tests, website integration and ZIP round-trip tests, and the live chooser in Brave with Discord Stable and Canary. The live visual test was cancelled before installation to keep running Discord sessions open.
