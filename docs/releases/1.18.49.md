# Moggcord 1.18.49

[Documentation](../README.md) / [Release notes](README.md) / 1.18.49

- The Windows installer checks for a newer stable installer when opened and automatically launches the verified update. A small progress view shows the download.
- Verified installer downloads are cached locally and reused on later launches. Failed checks, interrupted downloads and failed handoffs return to the current installer.
- The welcome screen uses the compact “Make it yours.” feature card with Plugins, Themes and Your setup.

Download this installer once to enable the new startup check. Installer files downloaded before this release do not contain the self-update feature. Discord is changed only after choosing and confirming an install, repair or uninstall action.
