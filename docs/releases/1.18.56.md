# Moggcord 1.18.56

[Documentation](../README.md) / [Release notes](README.md) / 1.18.56

- Include FakeDeafen as one of the four enabled default plugins, with its account-panel button visible on new installations. Add saved mute/deafen options, a button visibility setting and an optional Ctrl+Shift+Q shortcut.
- When enabling Fake Deafen from real full mute, mute the microphone before turning the headphones on. Keep the advertised full-mute state and leave the microphone muted when disabling fake mode.
- Preserve existing FakeVoice enabled/disabled preferences under the FakeDeafen name. Existing users who disabled the plugin or its button can enable them in Plugins.
- Separate plugin settings, enabled themes and QuickCSS between Discord Stable, Canary, PTB and other clients. Migrate the former shared settings only to Stable and retain the original files.
- Use the selected client's settings for community installs. Share installed plugin code and theme files while keeping each client's enabled choices independent.
- Reduce redundant profile badge refreshes, limit cached profiles and add request timeouts and malformed-response handling.
- Fix Server Info modal resolution and the current Discord voice action lookup.
- Preserve Discord-owned voice modules, codec DLLs and native module configuration during Windows installation. A locked `discord_voice.node` no longer aborts the final asset-copy step.
- Prevent newer Windows installers from downloading an older online payload over their bundled build. Verify the bundled build before extracting it.

Existing installations can update with the in-client updater or the new installer's **Repair** action. Fully restart the selected Discord client to load the changes.
