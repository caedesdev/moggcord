# Moggcord 1.18.52

[Documentation](../README.md) / [Release notes](README.md) / 1.18.52

- Fix Canary hanging at startup when Discord exports module values through its new loader format. Moggcord now handles both getter exports and direct value exports.
- Mark completed modules as loaded so React, icon utilities and other dependencies remain available to the module finder in the current Canary runtime.
- Keep the message-cache limits, event-log cleanup and reduced background work prepared in 1.18.51.
- Insert window drag protection once per document instead of polling after startup and adding duplicate styles on channel changes.
- Release plugin event subscriptions on stop without stacking handler wrappers on every restart.
- Skip distribution scanning and file copies when Moggcord is already running from its installed directory.
- Add startup regression coverage for constructor exports, lazy getters, existing exports and direct values.
