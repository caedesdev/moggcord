# Moggcord 1.18.51

[Documentation](../README.md) / [Release notes](README.md) / 1.18.51

- MessageLoggerEnhanced now applies its memory cache limit to stored logs as well as recent messages. Evicted records remain available in the saved database.
- Deleted-message rendering and message conversion caches have fixed bounds. Stopping the plugin releases their entries.
- EventLogs releases unread entries when they expire from the visible history and when the plugin stops. Restored history follows the existing 10,000-entry limit.
- Stealth mode uses the existing CSS rules instead of scanning the Discord interface after every page change. Toolbar buttons update once per toggle.
- The Windows installer includes the .NET runtime and can update itself when opened.
