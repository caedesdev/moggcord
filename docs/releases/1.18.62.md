# Moggcord 1.18.62

[Documentation](../README.md) / [Release notes](README.md) / 1.18.62

## Themes

- Restore the Theme Library entry directly below Themes. Its catalog, previews and stylesheets load from the library's own server.
- Apply enabled themes even when Moggcord starts after Discord has loaded.
- Manage themes from the same layout as Plugins, with counts, a progress bar, search and filters. Theme cards use text labels for their source. Import and folder controls are under the gear button.

## Images

- Fix a crash that could occur when opening the right-click menu on an image with ImageZoom enabled.

## Downloads

Update from Moggcord settings in Discord or use the installer for your operating system. The macOS and Linux installers are preview builds. Technical assets and checksums are published under [updates-v1.18.62](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.62).
