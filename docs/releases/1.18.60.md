# Moggcord 1.18.60

[Documentation](../README.md) / [Release notes](README.md) / 1.18.60

## Plugin management

- Show enabled and total plugin counts with a progress bar, a settings shortcut, and a confirmed Disable All action.
- Load plugin cards progressively to keep the settings page responsive when opening, searching, filtering, and closing it.
- Cancel tutorial availability requests when cards leave the page and avoid rerendering the full list for unrelated tutorial checks.

## Downloads

Update from Moggcord settings in Discord or use the installer for your operating system. The macOS and Linux installers are preview builds. Technical assets and checksums will be available under [updates-v1.18.60](https://github.com/caedesdev/moggcord/releases/tag/updates-v1.18.60).
